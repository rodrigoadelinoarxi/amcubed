=========================
Sale  - Portugal / Angola
=========================

* Sales now have a post button before sending to the customer.

* Restricts creating sale order lines without one VAT Tax.

* Restricts printing draft sale orders.

* Restricts creating sale order lines with negative values (quantities, unit prices or discounts).

* Restricts creating sale orders with customers without a Reference.

* Restricts creating sale order lines with products without an Internal Reference.

* New Rewrite action on sale orders to cancel and duplicate a sale order.

* Restricts editing fields on posted sale orders.

* Sale downpayments are not considered as fiscal relevant lines.

* Restricts creating sales with amounts above 9999999999999.99.

* Sale Orders now ask for a reason when cancelling.

* Proformas are now a different sale order (instead of just a different print button)

* New action to generate proformas from sale orders.


Installation
============

To install this module, you need to:

#. Download the module
#. Unzip to the addons path
#. Install module in Odoo Community or Enterprise
